# マネタイズ方針メモ

現時点では、DraftBoxに課金、AI API、Supabase上のプラン管理テーブルは実装していない。
そのため、画面上で「AI校正」「PDF」「共同編集」などの未実装機能を有効機能のように表示しない。

## まず無料で磨く価値

- 未ログインでも使える文字数カウント、Markdown編集、エクスポート
- ローカル自動バックアップとスナップショット復元
- アウトライン、読了時間、原稿用紙換算、簡易レビュー
- ログイン時のクラウド下書き保存と共有リンク

## 有料化するなら必要な土台

- Supabase: profiles または user_plans テーブルでプラン状態を管理
- Supabase: usage_events / ai_requests で利用量を記録
- Stripeなどの課金連携
- AI APIキー、利用上限、失敗時のフォールバック
- Pro機能の権限制御をUIだけでなくAPI/DB側にも実装

## 将来の有料候補

- AI校正、要約、タイトル案、構成改善
- PDF/Wordエクスポート
- 共有リンクの高度な権限と期限管理
- チーム用の共同編集、コメント、履歴比較

## 実装順序

1. 無料体験を安定させる
2. Supabaseにプランと利用量のスキーマを追加する
3. Stripe連携を追加する
4. AI APIをサーバー側Route Handler経由で呼び出す
5. Pro導線を画面に出す

未実装の段階では、画面ではなくこのメモに留める。
